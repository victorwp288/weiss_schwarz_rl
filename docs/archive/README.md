# Archive

This directory is for historical notes and legacy-route provenance. It is not a
thesis workflow surface.

Use `python -m weiss_rl.cli` and `configs/thesis/` for standard work. Legacy
script or preset paths should only be used for compatibility, diagnosis, or
artifact reproduction, and any such use should be recorded in
`docs/rebuild_log.md`.

## Contents

- `top_level_notes/`: historical status reports, rescue notes, draft result
  notes, and old master-plan documents moved out of the repository root.
- `reports/202605/`: dated May 2026 model-lock, rebuild-report, god-search,
  figure-audit, artifact-inventory, private-backup, and older refactor-audit
  docs retained as history rather than canonical onboarding material.
